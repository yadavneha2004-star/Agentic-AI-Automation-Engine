# Development Guide

## Overview
This repository uses a browser-based development workflow and Streamlit Cloud deployment.

## Code Standards
- All Python code follows standard PEP 8 formatting.
- Features are developed and verified through automated GitHub Actions tests.

## Commit Message Standards
- `feat:` New feature or capability
- `fix:` Bug fix
- `docs:` Documentation updates
- `test:` Unit test additions or updates
- `style:` Formatting or UI/UX improvements
